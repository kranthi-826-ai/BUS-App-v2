# Driver demo guide

1. Install the development APK on the driver phone.
2. Allow location while using the app, then allow background location when prompted.
3. Set battery usage to unrestricted for the app.
4. Sign in with the driver account.
5. Confirm the assigned Route 8 bus.
6. Slide to start the trip before moving.
7. Keep the phone secured and charging; the app publishes only during an active trip.
8. End the trip when the bus reaches campus.
